# 視覺規範

依據使用者的兩份簡報整理：
- **單排**：一份研究提案簡報（Google 簡報）
- **雙排**：一份論文報告簡報（PowerPoint）

兩者都是使用者會用的風格，共用同一套基礎，只在導覽列與頁面結構上不同。

1. 共用基礎

## 1. 共用基礎

- 16:9；字型用微軟正黑體（`Microsoft JhengHei`），參考文獻的英文論文標題用 `Times New Roman`。
- 頂部導覽列顯示報告進度，目前所在的章節為藍色實心（`1085DE`）。
- 導覽列下方有一條橘色分隔線（`FF9900`）。
- 一頁一個重點，以圖為主；完整說明放講者備註。
- 固定會有：問題 → 解法對照頁、參考文獻頁。
- **不加**章節分隔頁、大綱頁、Q&A 頁。

## 2. 單排風格

| 元素 | 規範 |
|---|---|
| 導覽列 | 一排膠囊分頁置中；目前章節 `1085DE` 白字，其他章節淺藍 `B7DAF5` 白字 |
| 分隔線 | 橘線橫跨整頁，位於分頁下方 |
| 章節 | 本身就是故事線，例如：問題背景／概念提案／應用方向（或後續方向）／參考文獻 |
| 頁面標題 | 左上「/ 」加膠囊標籤：紅色＝問題、綠色＝解法、藍色＝中性；問題與解法用相同編號（一、二、三） |
| 版面 | 左文右圖（文字約佔 35–40%）；也可以一頁放 2–3 張並排圖 |
| 封面 | 標題置中，下方橘線，再下面是「作者．用途」；無導覽列 |
| 結尾 | 左綠右紅對照頁（應用 vs 限制），中間用橘色直線分隔 |
| 頁碼 | 無 |

## 3. 雙排風格

| 元素 | 規範 |
|---|---|
| 導覽列第一排 | 章節膠囊分頁；目前章節 `1085DE` 白字，其他章節灰色（`BFBFBF`）白字 |
| 導覽列第二排 | 子章節小膠囊**嵌在橘線上、靠左**（不貼齊左端）：左側留一小段橘線，子章節列之後橘線延伸到右側；目前子章節為藍底白字，其他為灰底白字 |
| 章節 | 通用名稱：介紹／研究方法／實驗結果／結論 |
| 子章節 | 放故事線，例如：領域背景 → 過往研究 → 研究動機；核心概念 → 各個方法元件 → 任務推論；模型訓練 → 各類實驗 → 質化分析 → 消融實驗 |
| 頁面標題 | 左上粗體黑字（例如「Vision-Language（視覺語言）」），可以附一行灰色說明；以圖為主的頁面可以不放標題 |
| 問題的呈現 | 放在架構圖或示意圖下方的紅色橫條結論（紅底白字，全寬）；所有問題最後在「研究動機」彙整成對照頁 |
| 封面 | 會議名稱藍色小徽章（例如 NeurIPS 2022）→ 論文標題（襯線粗體）→ 橘線 → 作者與機構分兩欄 → 右下角「報告者：〇〇〇」 |
| 結論 | 「貢獻」：成果 → 綠色箭頭 → 效益；「未來展望」：條列 |
| 頁碼 | 右下角，灰色小字，封面不顯示 |

## 4. 配色系統

**固定色**（兩種風格都一樣）

| 用途 | 色碼 |
|---|---|
| 目前章節、中性標籤、強調文字 | `1085DE` |
| 未選分頁（單排／雙排） | `B7DAF5`／`BFBFBF` |
| 分隔線 | `FF9900` |
| 內文 | `595959`；標題 `222222` |
| 問題（標籤、結論橫條、對照頁左側） | `E06666` |
| 解法（標籤、對照頁右側） | `8CD96A`；淺底 `C9E2BE` |
| 架構圖中本頁新增或有變化的元件 | 綠色描邊 `6AA84F`，淺綠底 `D9EAD3` |
| 截圖上的重點 | 紅框 `FF0000`，線寬 2pt，不填色 |
| 淡化（漸進聚焦中非重點的部分） | 透明度約 70%，或文字改為 `C0C0C0` |

**概念色**：每份簡報依內容挑選，最多 4 個，依序使用：

| 槽位 | 底色 | 描邊／文字 |
|---|---|---|
| 概念 1 | `B6CFF5`（藍） | `3C78D8` |
| 概念 2 | `FFECB3`（黃） | `BF9000` |
| 概念 3 | `D9D2E9`（紫） | `674EA7` |
| 概念 4 | `D0E0E3`（青灰） | `45818E` |

概念色的使用規則：
- 用來區分論文裡**反覆出現、需要對照**的概念，例如「圖像層級＝藍、區域層級＝黃」。
- 一個概念指定顏色後，**整份簡報都不能換色**：該概念的區塊、表格列的色塊、時間軸的分類帶都使用同一個顏色。
- 紅色和綠色保留給「問題／解法」，不能拿來當概念色。
- 只有一組概念需要區分時，就只用概念 1，不必硬湊。

## 5. 共用呈現手法

**漸進聚焦**：同一組元素（圖、架構圖、條列）連續出現好幾頁，每頁只有一塊維持原色，其餘淡化。
適合用在逐一介紹任務類別、逐一說明模型元件、逐一解讀實驗表格。聚焦的順序要和子章節或講述順序一致。

**原生架構圖**：用方塊與箭頭繪製模型流程（輸入 → 特徵提取 → 融合 → 輸出）。
介紹過往研究時，每頁畫一種架構並在下方放紅色結論橫條；介紹本文方法時，沿用同一張圖，
把新加入的元件用綠色描邊標出。

**截圖標註**：論文的表格或圖使用截圖，上面疊加紅框（重點數值）、半透明概念色塊（標出列的分組，
例如「相同參數量」）、箭頭與一句話說明（例如「用執行效率換來的」）。說明文字寫在截圖旁邊，不要蓋住數值。

**時間軸**：橫軸為年份，縱向用概念色帶區分類別，模型名稱用小膠囊或方框。

**左右對照**：左綠右紅，或兩個概念色各佔一側。

## 6. 不要做的事

- 不要把論文章節名稱（Introduction、Related Work 等）直接當成單排的章節。
- 不要在標題下方加裝飾線（橘線只放在導覽列下方和封面標題下方）。
- 不要用陰影、漸層或裝飾性圖示。
- 不要為了填滿版面而加文字；圖放不滿時，寧可留白。
